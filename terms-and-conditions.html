4. Creator interactions and call preferences

Svoopy provides interactions between users and creators. Svoopy does not provide direct user-to-user chat or calling features.

Regular calls

Creators manage whether they accept regular calls in My Services. If a creator turns calling off, users cannot place regular calls to that creator while the setting is disabled.

Toc Toc calls

Users manage incoming Toc Toc call types in My Account → Toc Toc. A user can turn off audio calls, video calls, or both. A creator’s Toc Toc call using a disabled type will not be received by that user. If both types are disabled, the user will not receive Toc Toc calls.

Call preference settings control call availability. They do not change your wallet balance, profile location, or access to a replay you have already purchased.
